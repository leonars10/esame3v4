  ### come installare NVM su Mac
# Per installare NVM (Node Version Manager) su Mac, puoi seguire questi passaggi:
1. Apri il terminale.
2. Esegui il seguente comando per scaricare e installare NVM:
```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash
```
3. Dopo l'installazione, chiudi e riapri il terminale o esegui il seguente comando per caricare NVM:
```bash
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh" # This loads nvm
[ -s "$NVM_DIR/bash_completion" ] && \. "$NVM_DIR/bash_completion" # This loads nvm bash_completion
```
4. Verifica che NVM sia stato installato correttamente eseguendo:
```bash
nvm --version
